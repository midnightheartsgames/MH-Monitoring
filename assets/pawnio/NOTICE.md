# PawnIO — модуль AMDFamily17

Температура и мощность CPU AMD читаются через драйвер PawnIO (решение D4, PLAN.md §2.14). Сам
драйвер ставит его официальный установщик (<https://pawnio.eu>); приложение распространяет только
модуль, который загружает в драйвер.

бы его непригодным.

## Как приложение связано с PawnIO

Драйвер PawnIO распространяется под GPL-2.0 с исключением для программ, которые общаются с ним
только через интерфейс IOCTL устройства. Приложение именно так и работает: вызывает
`DeviceIoControl` напрямую и **не линкуется** с `PawnIOLib.dll`, лежащей в GPL-репозитории
драйвера.

Проверить файл:

```powershell
Get-FileHash .\AMDFamily17.bin -Algorithm SHA256
```
